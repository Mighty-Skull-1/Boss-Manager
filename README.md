## 🔥 The Grand Fusion: Kombat, Souls & GTA Mechanics

### 🥊 1. Mortal Kombat Combat System
- **Combo Counter & Announcer**: Chain melee slashes (`[LMB]`) to build your combo meter (*"8 HITS! BRUTALITY PACE!"*). Announcer calls out *"ROUND 1: FIGHT!"*, *"BURST DENIED!"*, and *"FATALITY!"*.
- **Hit-Stop Impact Physics**: Every heavy blow causes a visceral frame-freeze crunch with blood and fiery sparks flying across the arena.
- **[E] HOTFIX FATALITY / RIPOSTE**: When a speedrunner's posture is shattered, execute a screen-clearing, cinematic Fatality finisher dealing 9999 lethal damage!

### 🗡️ 2. Elden Ring Souls-like Mechanics
- **Posture & Poise Break**: Every enemy has a hidden posture gauge. Heavy Jump Slams (`[RMB]`) and combo hits break their posture, revealing a glowing orange critical reticle over their chest!
- **[T] Target Lock-On**: Dynamic camera tracks and orbits your locked target with Souls-style tracking.
- **[SPACE] Dodge Roll i-Frames**: Tumble through danger with invulnerability window trails.

### 🚗 3. GTA 5 Open Roam & Mayhem
- **★ ★ ★ ★ ★ 5-Star Wanted Level**: As you crush speedrunners and hotpatch exploits, your Speedrun Wanted Level climbs. At 4-5 stars, TAS AI Input-Bots and backup runners are dispatched to the raid arena with flashing sirens!
- **GTA GPS Radar Mini-Map**: Dynamic circular radar in the bottom-left corner tracking player heading, speedrunners, and hazards in real time.
- **[TAB / Q] Weapon & Ability Wheel**: Slow-motion radial wheel allowing instant switching between Greatsword Cleaves, Molten Slams, Lava Pillars, and Shockwaves.
- **[G] In-Game Radio Station**: Cycle between *Los Santos Synthwave*, *Elden Gothic Choir*, and *Cyber Speedrun Drill* with on-screen popups!

## 🕹️ Gameplay Mechanics

### 1. The Boss Action Sequencer (Scripting AI)
Queue up telegraphed boss attacks to break the speedrunners' rhythm and force them to burn their dodge rolls:
- 🗡️ **Infernal Cleave (15 MP)**: Wide 120° frontal sweep. Punishes greedy melee speedrunners.
- 💥 **Molten Ground Slam (25 MP)**: Massive circular seismic blast leaving burning embers.
- 📡 **Raid-Wide Shockwave (35 MP)**: Arena-wide expanding wave. Forces rolls or causes heavy stagger.
- ⚡ **Erupting Lava Pillar (20 MP)**: Geyser targeted directly under the furthest ranged caster.
- 👥 **Dev-Spawn Adds (30 MP)**: Fiery imps that harass potion chuggers and interrupt burst setups.
- 🌟 **Phase 2 Ultimates** *(Unlocked in Phase 2)*:
  - 🎯 **Apocalypse Sweeping Beam (40 MP)**: Arena-sweeping rotational death ray.
  - ✨ **Cataclysm Meteor Rain (45 MP)**: 5 molten meteors targeted on all runner positions.
  - ☀️ **Supernova Enrage (60 MP)**: Climactic full-screen raid-wiping explosion.

### 2. Live Hotpatching & Exploit Triage
Speedrunners will try illegal tricks in real-time:
- 🛑 **Out-of-Bounds Corner Clip**: The Rogue attempts to clip through wall geometry to attack from safety. *Deploy Hotfix: Seals collision mesh & stuns runner!*
- 🧪 **Unchecked Potion Overflow**: The Mage chugs 8 stacked potions to prepare a 1-shot burst skip. *Deploy Hotfix: Dispels illegal potion buffs!*
- 🔄 **Infinite Stagger Lock**: The Tank finds an animation cancel to keep the boss in perpetual hitstun. *Deploy Hotfix: Grants boss temporary super armor!*
- ⏩ **Coordinated DPS Skip**: The party synchronizes burst cooldowns to cross the 50% threshold in a single frame. *Deploy Hotfix: Activates defensive shield!*

### 3. Arena Floor Manipulator
Spend Dev Mana to modify the arena layout on the fly:
- 🔥 **Floor Collapse (Lava Pool)**: Melts floor tiles into bubbling magma, denying kiting shortcuts.
- 🛡️ **Hotfixed Collision Barrier**: Drops an impassable holographic barrier blocking corner skips.
- ⚠️ **Anti-Roll Caltrops**: Places floor spikes that nullify dodge roll i-frames and inflict bleed.

### 4. The Sacred Phase 2 Cutscene Button
When Boss HP approaches **50%**, the button unlocks with flashing alerts:
- Activating it freezes the raid clock, grants **100% Invulnerability**, triggers dramatic letterboxing, camera shake, and plays the boss's full melodramatic metamorphosis monologue!
- If timed right during a speedrunner burst window, you earn bonus **"BURST DENIED"** points and maximize Dark Lord approval!

### 5. Live Stream & Executive Feed
- **Live Speedrun Twitch Chat**: 200,000+ viewers reacting to your patches, gold splits, and near-wipes (*"HE PATCHED THE HITBOX LIVE LMAO"*, *"Sub-2 is DEAD"*).
- **Dark Lord DMs**: Real-time Slack/Discord messages from your tyrannical boss monitoring your KPIs.

### Running Locally
```bash

git clone git@github.com:Mighty-Skull-1/Boss-Manager.git
cd Boss-Manager

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🌐 GitHub Pages Setup

This repository is pre-configured with two deployment options:

### Option A: Automatic Deployment via GitHub Actions (Recommended)
1. Go to **Settings** > **Pages** in this GitHub repository.
2. Under **Build and deployment** > **Source**, change from *"Deploy from a branch"* to **"GitHub Actions"**.
3. Every commit to `main` will automatically build and deploy the game at `https://mighty-skull-1.github.io/Boss-Manager/`!

### Option B: Deploy from Branch (`/docs` or `/(root)`)
If you keep **"Deploy from a branch"**:
1. Under **Branch**, select `main` and choose **/docs** from the folder dropdown.
2. Click **Save**.
3. GitHub Pages will serve the pre-built game from the `docs/` folder!
